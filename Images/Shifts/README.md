# Shift File Guide

One of the WFC3 F814W images was aligned to GAIA first then all the other WFC3 images were aligned to that F814W image.

## File Guide

- `GAIA-Main-F814W.*`: The shift files for the WFC3 F814W that was aligned to GAIA.
- `GAIA-F814W.*`: The shift files for the WFC3 F814W that were aligned to the initial.
- `GAIA-F475W.*`: The shift files for the WFC3 F475W that were aligned to the initial.
